The Law

A signature is evidence, not decoration.

Brand Guide §08 already settled this: real ink, never a script font. These files are what that rule points at.

  1. Place the master. Never set a name in an italic face and call it a signature. An italic name is a stand-in for a signature that has not been applied yet.
  2. A signature is not a logo. It never replaces the wordmark, never appears in navigation, on merchandise, or in a lockup, and never marks a page the way a mark does.
  3. Never redraw, retrace, or generate one. Scale the vector. If the size or color you need does not exist, request it.
  4. Only on Parchment or white. The ink is Midnight, so a dark ground erases it. Nothing signed goes on Midnight, on Word Blue, or over footage until a reversed master is published.
  5. Only on a document the signer has approved. Placing a signature is an act of the record. It is not a design decision.
The Kit

Seven masters, two signers.

Both names that approve this system are published here. Each master is a single closed path with proper interior counters, so it stays crisp at any size. Ink is Midnight #0B1A2D. Where a document carries both, Joel signs first.

Placement

SVG everywhere it is accepted.

The vector is the master. Reach for the PNG only where the destination refuses SVG. Every PNG is transparent and 1200px tall, so it stays sharp in print.

WhereUseWhy
A page in this portal.svgScales with the layout, adds no network weight worth counting.
Microsoft Word.svgInsert, then Pictures. Stays sharp when printed or exported to PDF.
Google Docs.pngDocs will not import SVG.
PDF forms and e-sign.pngTransparent, so it sits over a ruled signature line cleanly.
Email signature.pngMost email clients block SVG. Scale to roughly 180 to 220px wide.
Figma or Illustrator.svgImports as an editable path, so it can join a shared library.

Reversing it: change the fill value in the SVG to #FFFFFF. Never invert the PNG, which produces a grey halo where the strokes were anti-aliased. A reversed master is not published yet, so a reversed signature is not approved for release until one is.

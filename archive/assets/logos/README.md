# Superseded wordmark files

The six 368 x 32 pixel PNGs that served as the wordmark before the vector masters were
adopted. They are kept because `archive/brand-guide-v4.5.html` renders them, and an
audit citing that version has to be checkable against what it actually showed.

They are not published assets. They do not appear in `/ai/assets.json`, and nothing in
the live portal may link to them. The current marks are at `assets/logos/the-word/`.
